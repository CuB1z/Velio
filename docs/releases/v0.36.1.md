# 📦 Velio - Release v0.36.1

---

> **🧭 Summary**
>
> Patch release **0.36.1** of **Velio**. Nothing changes for riders: the backend now hands its shared resources to routes and services through explicit dependency providers instead of application state, and every Python dependency is pinned so CI and the images stop changing on their own.

---

## 📄 Release Notes

### 🧹 Maintenance

- **Shared resources through explicit providers**: the Valhalla client, the elevation source, the restricted areas, the covered regions and the mail sender are each built once by their own dependency getter instead of hanging off application state. Startup only loads them and shutdown closes them, so routes and services receive everything they use through dependency injection.
- **Sessions read the current session from the token**: the session list and "sign out other sessions" take the caller's session straight from the access token instead of a value another dependency left on the request, so they no longer depend on the order their dependencies are declared in. Responses are unchanged.
- **Pinned dependencies**: CI turned red with no code change when it picked up pytest 9.2, which rejects approximate comparisons over nested sequences in the polyline tests. Those tests now compare point by point, pytest is held to 9.2, and the last unbounded requirements are pinned to the versions CI runs: mypy 2.4.1, osmium 4.3.2 and numpy 2.5.4, which ships in the backend image.

### 🏷️ Version

- Backend and API contract bumped to **0.36.1**.
