# 📦 Velio - Release v0.36.0

---

> **🧭 Summary**
>
> Minor release **0.36.0** of **Velio**. Account emails now carry the brand and arrive in the language the rider uses, settings show how each account signs in, riders can ask to hear once when their country arrives, and the public pages are ready for search engines and language models. The backend tests now run on Postgres.

---

## 📄 Release Notes

### ✨ Features

- **Branded emails in English and Spanish**: the verification, password reset and account deletion emails share one dark layout with the Velio wordmark and the code on a pistachio block, fit phones, and are written in the language the rider is using on the web.
- **Settings show how you sign in**: Security lists the sign-in methods (email and password, Google, or both) and only offers the password form to accounts that have a password; a Google account is told it has no password to change instead of a form that failed.
- **"Email me when it arrives"**: the "Ask for your country" dialog has an unchecked box to hear once when Velio covers that country. Velio sends nothing itself: the operator exports who asked (`python -m tools.coverage_requests recipients XX`) and writes from the contact mailbox.
- **Search engines and AI assistants**: a generated `sitemap.xml` with language alternates, `robots.txt`, `noindex` on the sign-in screens, structured data on the landing, Open Graph cards on every page (with a default card for pages that are not prerendered), `llms.txt` and `/.well-known/security.txt`.

### 🗃️ Database

- Migration **0009** adds `notify`, `language` and `notified_at` to `coverage_requests`; it runs on startup.

### 🧹 Maintenance

- **Backend tests on Postgres**: every run starts a throwaway Postgres 16 with Testcontainers and applies the migrations, and a new test takes every migration up, down and up again.
- The privacy policy describes the country opt-in and the contact mailbox.

### 🏷️ Version

- Backend and API contract bumped to **0.36.0**.
