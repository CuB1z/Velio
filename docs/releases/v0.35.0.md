# 📦 Velio - Release v0.35.0

---

> **🧭 Summary**
>
> First production release of **Velio**, live at **[velio.cub1z.es](https://velio.cub1z.es)**. The backend and the web app now ship from one repository: a GitHub release builds both images, deploys them on Dokploy, waits for the new version to answer and runs a smoke test. The database is backed up every day, encrypted, to Backblaze B2. This release also adds the privacy policy and the terms of service, which Google requires before its sign-in can be published.

---

## 📄 Release Notes

### ✨ Features

- **Privacy policy and terms of service**: `/privacy` and `/terms`, in English and Spanish (`/es/...`), prerendered like the landing so they load with their final content. They are linked from the footer and from the sign-up consent, and the Google button notes that continuing accepts them.
- **One navbar and footer for every public page**: the landing's navbar now also leads back to its sections from the legal pages; the footer adds a row with Privacy · Terms · GitHub · Author.
- **Daily encrypted database backups**: a `db-backup` service dumps Postgres every day, encrypts the dump with GPG and uploads it to Backblaze B2 (EU), keeping 14 days. Older dumps are pruned only after a new one is stored, and one command restores the latest or a given dump.
- **Release pipeline**: CI per side (backend, frontend), images published to Docker Hub, and a release that deploys on Dokploy, waits for `/api/health` to report its version and runs the smoke test.

### 🐛 Bug Fixes

- **Text reflowing on load**: Geist is now self-hosted and preloaded, so pages paint in their final font instead of switching from the system font.
- **Language swapping after load**: the URL alone decides the language (no prefix is English, `/es` is Spanish); pages no longer jump to the stored or browser language once loaded.
- **Redeploys kept the previous images**: the app images are pulled on every deploy, since Dokploy runs `docker compose up` without `--pull`.
- **Long route titles on phones**: a saved route keeps its title in view next to its actions.

### 🧹 Maintenance

- **Monorepo**: the backend and the web app live together under `backend/` and `frontend/`, with every Compose file in `docker/`; both histories are kept.
- **License**: Velio is free software under the GNU AGPL-3.0.
- **Frontend structure**: component files in PascalCase and only routed pages under `pages/`.
- **Hermetic backend tests**: unit and API tests run on synthetic elevation tiles, with no local DEM needed.

### 🏷️ Version

- Backend and API contract bumped to **0.35.0**.
