# 📦 Velio - Release v0.35.1

---

> **🧭 Summary**
>
> Patch release **0.35.1** of **Velio**. Fixes the planner map showing an empty canvas in production: the start marker appeared, but no streets or labels.

---

## 📄 Release Notes

### 🐛 Bug Fixes

- **Blank map in production**: MapLibre 6 builds the URL of its worker at runtime, so the production build never shipped the worker file and the map could not decode any tile (`maplibre-gl-worker.mjs` answered 404). Vite now bundles the worker as an ES module and the map hands it to MapLibre with `setWorkerUrl`. Development was not affected because Vite serves the file straight from `node_modules`.

### 🏷️ Version

- Backend and API contract bumped to **0.35.1**.
