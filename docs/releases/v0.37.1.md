# 📦 Velio - Release v0.37.1

---

> **🧭 Summary**
>
> Patch release **0.37.1** of **Velio**. The app installed on an Android phone behaves better: the bar at the bottom of the screen is no longer white, pulling down never reloads the page, and the clock and battery stay clear when Chrome lets the app draw behind them.

---

## 📄 Release Notes

### 🐛 Fixes

- **A dark navigation bar on Android**: Chrome paints the system bar under an installed app with the colour declared in the app manifest, which was the light ground, so it showed a white strip under the dark theme. It now uses the dark ground. Chrome takes a single colour for both themes, so the bar stays dark in the light theme too. Reinstall the app to pick it up, or Chrome refreshes it on its own within a day.
- **No pull-to-refresh anywhere**: v0.37.0 stopped it inside the scrolling panels only. A pull that started on the header, the bottom bar or a page too short to scroll still reloaded the page and lost the route; the whole page now holds it.
- **The status bar stays clear**: when Chrome draws an installed app edge to edge (today behind the `web-app-short-edges-cutout-mode` flag), the content starts below the clock and the landing header sticks under it instead of behind it.

### 🧹 Maintenance

- A mobile end-to-end test emulates the status bar and navigation bar insets and checks that the header stays below the status bar on the landing, after scrolling, and in the planner.

### 🏷️ Version

- Backend and API contract bumped to **0.37.1**.
